# MultipurposeDiagramMaker

（2026-10-15 に旧名「ビジネスダイアグラムメーカー」から改名しました）

ブラウザだけで動作する、**単一 HTML ファイル完結**のビジネス図作成ツールです。
スイムレーン図メーカーを起点に、ノード配置・接続線ルーティング・保存/復元・各種エクスポートを
備えた汎用ダイアグラムエディタへ発展させました。インストール不要で、HTML を開くだけで使えます。

- **アプリ本体（最新版）**: [`アプリケーション本体/diagram_v8.32.html`](アプリケーション本体/diagram_v8.32.html)（2026-10-13）
- **操作マニュアル**: [`マニュアル/MultipurposeDiagramMaker_操作マニュアル_v8.32.docx`](マニュアル/MultipurposeDiagramMaker_操作マニュアル_v8.32.docx)
- 開発計画は [`開発資料/開発ロードマップ/開発ロードマップ.txt`](開発資料/開発ロードマップ/開発ロードマップ.txt)、
  変更履歴は [`開発資料/開発記録/開発記録.txt`](開発資料/開発記録/開発記録.txt) を参照してください。

---

## 特徴

- **単一 HTML ファイル完結** — 依存サーバー不要。ブラウザ（Chrome など）で開くだけで動作します。
- **コアエンジン共通化** — ノード配置・接続線ルーティング・保存/復元・エクスポートを全図種で共用し、
  図種ごとにパレット・レーン有無・描画だけを切り替える設計です。
- **後方互換の維持** — 既存のスイムレーン図機能はすべてのバージョンで動作するよう配慮しています。

## 対応図種

新しく作れる図は次の 5 種類です。

| 図種 | 補足 |
|---|---|
| スイムレーン図 | 起点となった図種。縦／横のレーン、グループ枠、複数レーンにまたがる工程に対応 |
| フローチャート | レーンなしで自由に配置。方眼への吸着に対応 |
| 樹状図 | 組織図・業務分掌図・決裁ルート図など（旧「組織図」を汎用ツリー図へ発展） |
| ガントチャート | 汎用カラムモデルにより各種工程表に対応。見出し欄・承認欄・凡例、Excel(.xlsx) 出力 |
| マインドマップ | 合意状態・重要度などの属性、リザーブ、Markdown／OPML／FreeMind の入出力 |

BPMN・状態遷移図・ER 図・シーケンス図・UML クラス図は、新しく作る図種としては選べませんが、
これらで保存したファイルは従来どおり開いて編集できます。

## 主な機能

- 図形の配置・接続（○＋からの 1 クリック接続）、シェイプを避けて直角に折れる接続線（A* 経路探索）、交差点のブリッジ
- レーンのガイドや接続相手に合わせて吸着する配置、スペース挿入・スペース調整、整列
- グループ枠（L 型・凹型・凸型・階段状の切り欠き）、ステップ図の挿入
- コピー＆貼り付け（別のウィンドウの図からも）、検索・置換、文字サイズ・色・点線・デザインの切り替え
- 上書き保存（Ctrl+S）。保存したファイルは図のデータを埋め込んだ HTML で、開けば続きから編集できます
- 出力: **PDF（印刷。用紙・向き・ページ数の指定と改ページ位置の表示）／ PNG ／ Excel(.xlsx)**、テキストからの作図

## 使い方

`アプリケーション本体` フォルダの [`diagram_v8.32.html`](アプリケーション本体/diagram_v8.32.html) をブラウザで開くだけです。
このフォルダに置くのは常に最新版 1 本だけです（過去版は Git の履歴から取り出せます）。
操作方法は `マニュアル` フォルダの操作マニュアル（Word）を参照してください。

## 開発補助スクリプト（任意）

スクリーンショット取得などの補助スクリプトを使う場合のみ、依存をインストールします。

```bash
npm install                          # Puppeteer / docx を取得（リポジトリのルートで）
node マニュアル/作成ツール/serve.js   # ローカルでプレビュー（http://localhost:8765/ で本体が開く）
```

本体（`アプリケーション本体/diagram_*.html`）の利用自体には何のインストールも不要です。

### 操作マニュアルの再生成

マニュアル（.docx）は本体と同じ版番号で管理しています。リポジトリのルートで次の順に実行すると再生成されます。

```bash
node マニュアル/作成ツール/serve.js              # 別ターミナルで起動したままにする
node マニュアル/作成ツール/capture-puppeteer.js  # screenshots/manual/ に画面を撮り直す（章を絞るときは m03 m05 のように指定）
node マニュアル/作成ツール/create-manual.js      # マニュアル/MultipurposeDiagramMaker_操作マニュアル_vX.YZ.docx を出力
```

- 役割: 撮影の手順と注釈（赤枠・番号・カーソルの絵）＝`capture-puppeteer.js`、原稿＝`manual-content.js`、
  Word への描画＝`create-manual.js`（`--preview` を付けると同じ原稿の確認用 HTML `screenshots/manual/_preview.html` も出力）。
- 撮影は puppeteer があればそれを、無ければ playwright の Chromium を使います。npm を使えない環境
  （Claude Code のクラウド環境など）では `NODE_PATH=/opt/node-tools/node_modules` を付けて実行します。
  Linux では日本語が中国語の字形にならないよう、IPAPゴシックを優先する設定を自動で使います。

版を上げたときは `マニュアル/作成ツール/` の `capture-puppeteer.js` の `URL`・`serve.js` の既定のページ・`create-manual.js` の `APP_VERSION` も
新しい版に合わせてください（旧版はリネームで消えるため、放置すると撮影が 404 で落ちます）。
マニュアル本体（`マニュアル/` の .docx）はリポジトリで管理しています。撮影した画面（`screenshots/`）とそれ以外の .docx・.pdf は
`.gitignore` 対象で、リポジトリには含まれません。
